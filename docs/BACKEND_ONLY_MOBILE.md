# Подключение приложений заказчика и Pro к бэкенду

Ветка `fix/backend-only-mobile` переводит рабочие операции обеих версий на REST API собственного бэкенда. Flutter использует Firebase Core и Messaging для FCM. Авторизация, профили, адреса, поиск адресов, каталог, расчёт цены, пакеты, заказы, допуслуги, бонусы, рефералы, очередь подключения домов и учебные материалы обслуживаются бэкендом и PostgreSQL. Медиа хранится через серверный сервис хранения. Демонстрационные данные доступны только в debug-сборках.

Добавлены серверные проверки цен и оплаченных допуслуг, реферальные начисления с защитой от повторного начисления, заморозка пакета и удаление аккаунта с отзывом сессий. Финансовые записи при удалении аккаунта сохраняются, персональные данные обезличиваются; активные заказы требуют завершения.

## Ссылки и выпуск

- Заказчик: `https://domly.kz/customer/`
- Pro: `https://domly.kz/pro/`
- Администратор: `https://domly.kz/admin/`
- Нативные схемы: `domly://customer/`, `domly-pro://pro/`.

Nginx обслуживает Flutter-сборки из `frontend/releases/current`. `scripts/deploy_web_all.sh` собирает и готовит атомарный статический релиз. GitHub CI проверяет приложения, собирает три веб-версии и передаёт их backend deployment workflow. Firebase Hosting/Functions не используются этим процессом выпуска.

Перед production-выпуском применить добавления из `backend/sql/schema.sql`, опубликовать API и статические сборки, установить `ANDROID_CUSTOMER_CERT_SHA256` и `ANDROID_PRO_CERT_SHA256` из Play Console (сертификаты подписи приложений), проверить `APPLE_TEAM_ID` и associated domains. Без Android fingerprints endpoint assetlinks возвращает 503: автоматическое подтверждение HTTPS-ссылок невозможно. Подписание iOS и проверка push на реальных устройствах требуют macOS и учётных данных выпуска.

Каталог видео теперь читается из PostgreSQL. Настоящие материалы необходимо добавить через администратора; демонстрационные ссылки не импортируются. Для реальных SMS, оплаты и push нужны действующие серверные настройки провайдеров. Ранее встроенные ключи WAPPI и геокодирования удалены из клиентских build-скриптов; опубликованные ранее ключи следует заменить у провайдера.

## Проверено в облачной среде

Установлены Flutter 3.44.1 / Dart 3.12.1 и Android SDK 36 (Build Tools 36.0.0, NDK 28.2.13676358). Переменные доступны через `/workspace/domly-cloud/mobile-env.sh`.

Backend: 53 проверки прошли, включая интеграционные проверки с PostgreSQL. Flutter: 44 теста прошли. Веб-сборки заказчика, Pro и администратора созданы. Статические страницы обеих версий и Apple association endpoint проверены через локальный Nginx. В Flutter analyzer остаются предупреждения, компиляционных ошибок нет.

Проверки в облаке не означают публикацию production-релиза или успешную проверку SMS, банковской оплаты и FCM на реальном устройстве.
