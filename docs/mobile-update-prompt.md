# Уведомление об обновлении мобильных приложений

DomLY и DomLY Pro проверяют публичную версию своего package/bundle ID в Google Play или App Store (регион KZ). Проверка выполняется при запуске и возврате из фона. Для web и админки окно отключено.

При наличии более новой версии открывается окно с кнопками «Обновить» (переход на карточку приложения в соответствующем магазине) и «Позже». После откладывания повторное предложение показывается не раньше чем через сутки. Новая версия может быть предложена раньше. Недоступность магазина или отсутствие карточки не блокирует приложение. Проверка магазина не авторизуется и не передаёт данные аккаунта DomLY.

При каждом релизе нужно увеличивать **version name** в `pubspec.yaml` (например, `1.0.14+24` → `1.0.15+25`); одного увеличения build number недостаточно для сравнения публичных версий магазинов. Проверяется доступная публичная версия; закрытые тестовые треки Google Play этим механизмом не проверяются.

Первый релиз с механизмом обновления пользователь должен установить через магазин вручную. Серверный деплой не добавляет окно в уже установленную старую версию. Публикация требует подписанной Android/iOS-сборки, доступа к Google Play Console/App Store Connect и прохождения проверки магазинов.

Проверки: `flutter test test/utils/store_update_prompt_test.dart` — Android/iOS, новая/текущая/старая/недоступная версия, откладывание и отключённые поверхности. Перед выпуском проверить на устройствах переход в магазин и показ окна с опубликованной более новой версией.
