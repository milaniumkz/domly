Покупка пакета на iOS/Android останавливалась до выставления счёта: установленный клиент автоматически вызывал проверку площади без документа. Сервер теперь пропускает только этот старый предварительный запрос, если он относится к собственному неоплаченному пакету. Заявка на проверку не создаётся, площадь не подтверждается, требование техплана для настоящих заявок сохраняется. Новый клиент больше не выполняет этот лишний запрос.

Для уборки после ремонта калькулятор открывает условия и оплату без допуслуг; сервер запрещает добавлять их в расчёт и публикует признак allowAddons. Цена из админки сохраняется. Остальные тарифы поддерживают допуслуги.

Реферальная ссылка заранее загружается в трёх точках входа. Окно «Поделиться» вызывается из нажатия без сетевой задержки, получает координаты для iOS; при ошибке остаётся ссылка с кнопкой копирования. Серверная совместимость оплаты работает без обновления установленного приложения; изменения встроенного интерфейса/системного share требуют новой клиентской сборки, веб получает их при деплое.

Проверки: полный backend с PostgreSQL, Flutter tests/analyze, браузерная проверка мобильных размеров с успешным и отклонённым Web Share. Настоящие счета, сообщения и списания при проверке не создаются.
