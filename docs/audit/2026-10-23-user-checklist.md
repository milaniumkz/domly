## Повтор 18:55 UTC

Дополнительно воспроизведены и исправлены связанные с пользовательскими жалобами ошибки:

- При сбое истории отмена уже сохраняла cancelled, поэтому нельзя было повторить возврат. Отмена, посещение, бонусы, статусы и сохранённые уведомления теперь одна транзакция.
- При сбое изменения платежа возврат бонусов оставался отдельно. Возврат платежей сериализован и использует ту же транзакцию; 8 конкурентных повторов дают один возврат.
- applied_at ставился до активации пакета. Применение paid, пакет, начисления, заявка качества и записи уведомлений теперь атомарны; доставка уведомлений происходит после commit. Сбой оставляет применение доступным для повтора. Оплата заказа также использует один transaction client и возвращает HTTP-успех после commit.
- Оплата новых допуслуг не возвращает уже начатую/завершённую уборку в assigned.

UI cancellation_atomicity: 500 без изменения → 200 cancelled, баланс 10000, доступных посещений 5, одно уведомление. Сценарии синтетические. Код финансовых правил не менялся.
