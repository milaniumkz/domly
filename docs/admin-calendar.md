# Календарь админки

Откройте **Календарь** в меню после раздела **Заказы**. Выберите дату в месяце: ниже появятся все клинеры и их записи. Кнопка **Другая дата** возвращает к месяцу.

- Ячейки с записями выделены зелёным. В ячейке — количество заказов и площадь.
- В карточке клинера показаны утверждённые рабочие часы, суммарная площадь за день, норма 220 м² и максимум 250 м².
- Цветные интервалы показывают записи; ниже — время, клиент, адрес и статус каждого заказа. Нажатие открывает существующие детали заказа.
- Командный заказ виден у каждого участника с его долей площади. В общей сводке заказ и его полная площадь учитываются один раз.
- Завершённая уборка остаётся в истории и дневной площади, но больше не занимает время. Отменённые записи по умолчанию скрыты и не увеличивают нагрузку.
- «Выходной» означает, что неделя утверждена, но рабочий день не задан. «График не утверждён» означает отсутствие утверждённого графика. Свободные интервалы показываются только по утверждённому графику.
- Заказы без полной команды собраны отдельно в блоке **Нужно назначить исполнителей**. У заказа видны принятые/зарезервированные места и активные предложения.
- Пересечения, неизвестное время, отсутствие допуска и записи вне графика отмечаются предупреждениями; календарь ничего не переназначает автоматически.

Фильтры свёрнуты под кнопкой **Фильтры**: поиск клиента/адреса/телефона/номера, выбор клинера, только клинеры с записями, отображение отменённых заказов. Данные обновляются каждые 30 секунд и кнопкой обновления.

## Сервер

`GET /api/v1/admin/calendar?from=YYYY-MM-DD&to=YYYY-MM-DD` — только `admin` и `superadmin`, максимум 62 дня. Возвращает единый read-only снимок PostgreSQL (repeatable read): заказы, назначения, доли участников команды, рабочие дни, утверждённые недели, доступных клинеров и исторических участников записей. Первая страница/произвольный лимит записей не используется. Заказы, начавшиеся до периода и продолжающиеся в нём, также включены. Ответ не кешируется.

На клиенте дни и назначения индексируются один раз после загрузки месяца, чтобы повторные отрисовки не перебирали весь месячный массив для каждого клинера. Суммы площади не зависят от фильтра поиска внутри карточки клинера: это фактическая нагрузка за весь день.
