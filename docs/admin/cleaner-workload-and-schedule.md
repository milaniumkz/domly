# Выработка уборщиц и недельный график

## Минимальный интервал

Для уборок начиная с **1 декабря 2026 года** между окончанием одного заказа и началом следующего у каждого участника команды должно быть не менее **90 минут**. Ровно 90 минут разрешены. Проверка действует при выборе времени, оформлении, назначении, принятии заказа, переносе и увеличении длительности допуслуг. Учитываются также предварительные резервы и переход через полночь.

Правило определяется датой уборки по времени Астаны. Ноябрьские уборки сохраняют прежнее поведение. Существующие заказы не отменяются и не переносятся автоматически.

## Уборщицы → Выполнено за период

Выберите начальную и конечную даты (обе включительно). В карточке каждой уборщицы отображаются:

- площадь выполненных уборок;
- количество отработанных дней — уникальных дат завершения уборок по времени Астаны (несколько уборок за день считаются одним днём);
- время по заказам — сумма расчётной длительности завершённых уборок (при отсутствии сохранённой длительности используется интервал начала и окончания заказа, включая переход через полночь);
- фактическое время по отметкам начала и завершения;
- количество выполненных уборок;
- количество уборок без достоверных отметок времени.

По умолчанию выбран текущий месяц до сегодняшнего дня. Период относится к дате завершения по времени Астаны, а не дате регистрации сотрудника. Для старых заказов без отметки завершения используется запланированная дата; их часы не подменяются расчётной длительностью.

У командной уборки каждый участник получает только свою долю площади и своё фактическое время. Завершённая часть участника учитывается, даже если остальные участники ещё работают. Отменённые заказы не учитываются. При ошибке загрузки отображается ошибка, а не ложные нулевые итоги.

## Графики работы

На широком экране слева находятся заявки с кнопками одобрения и отклонения, справа — недельные карточки уборщиц. На телефоне заявки расположены сверху, график — ниже.

Стрелки переключают недели назад и вперёд без ограничения текущей и следующей неделями; кнопка «Текущая неделя» возвращает к сегодняшней. В каждом дне видны утверждённая смена, выходной либо отсутствие утверждения, заказы с временем и долей площади, свободные интервалы и дневной итог площади. С декабря свободные интервалы учитывают 90-минутные промежутки. Карточку заказа можно открыть нажатием.

После решения по заявке недельный график обновляется, сохраняя выбранную неделю. Данные также обновляются каждые 30 секунд. Доступ — только администраторам.

Ограничение интервалов работает на сервере без обновления клиентского приложения. Для новых экранов в установленном APK админки требуется новая сборка; веб-админка обновляется деплоем.
