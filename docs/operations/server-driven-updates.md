# Изменения без новой мобильной сборки

Поддерживаемый путь: администратор сохраняет данные на сервере, приложение получает их через существующие API. Не загружать исполняемый Dart/JavaScript-код вместо обновления приложения и не менять контракты старых версий.

| Что менять | Где | Доставка |
|---|---|---|
| Фразы интерфейса RU/KK и шаблоны с параметрами | «Тексты и переводы» | `/translations`; обновление словаря каждые 30 секунд; стандартные фразы остаются при ошибке загрузки |
| Полная оферта, политика, информационные страницы | Редактор информационных страниц | `/content-pages/:slug`; полные тексты и отдельные переводы, безопасная прокрутка |
| Пакеты, дополнительные услуги, баннеры, акции | Соответствующие разделы админки | Каталог и `/app/bootstrap`; финансовые значения меняет только уполномоченный администратор |
| Существующие параметры формы «Настройки» | «Настройки» → «Редактировать политики» | `/admin/settings`; сохраняется карта настроек, документы не затрагиваются |
| Серверные статусы, проверки, интеграции | Проверенный релиз backend | Сохраняются совместимость API, аутентификация и идемпотентность |

Существующие экраны получают поддерживаемые значения с сервера. Произвольный новый ключ настройки сам по себе не добавляет поведение: его обязан поддерживать клиент или сервер. Новые экраны, нативные разрешения, камеры/SDK, неподдерживаемые виды компонентов и изменения локальной логики требуют сборки приложения.

Управление всеми жёстко заданными серверными push-фразами и всеми элементами UI ещё не централизовано. Нельзя считать любую запись в runtime metadata работающей функцией без проверки её потребителя. Расширять конфигурацию следует добавлением необязательных полей с прежними значениями по умолчанию, тестом старого клиента и повтором пользовательского сценария. При ошибке загрузки сохраняются последние доступные данные либо штатные значения; обновление не должно сбрасывать текущую форму или повторять платежи.

24.10.2026: исправлена неверная отправка формы общих настроек в `/admin/content-pages`. Регрессия `test/e2e/admin_settings.cjs` выполняется только на изолированном стенде: сохранение, чтение с сервера, неизменность документов. Тест не запускается на production и не меняет реальные тарифы/бонусные правила.

Дополнительно удалена устаревшая клиентская метка Firestore из REST-запроса; сервер сам выставляет updated_at. Списочный ответ bulk-настроек обрабатывается методом postList без изменения контракта API. Проверки 200/403 сохраняют требования аутентификации. Финальный браузерный повтор подтвердил закрытие формы, повторное открытие, доставку значения через bootstrap и неизменность документов.

## Цены в карточках калькулятора

14.11.2026: опубликованный калькулятор переводит название пакета через `.tr()`, но в подписи карточки выводит только общую формулу. Публичные `/translations`, `/app/config` и `/app/bootstrap` теперь формируют переводы названий с действующим базовым тарифом из `catalog_packages`: например `Разовый пакет · 95 ₸/м²`. Казахская подпись использует казахское название пакета. При фиксированной цене или смешанном тарифе показываются соответствующие составляющие за одну уборку.

Это базовая ставка до скидок, а не сумма за месяц или квартал. Персональная сумма по площади, количеству уборок, дополнительным услугам и скидкам по-прежнему приходит из `/packages/quote`. В публичные переводы не включаются персональные цены или данные адресов. Совпадающие названия с разными тарифами не получают неоднозначную подпись.

Исходные названия, идентификаторы, числовые тарифы, условия согласия и записи переводов в БД не меняются. Подпись вычисляется при чтении, поэтому обновление тарифов через админку автоматически обновляет текст. Сохранение пакета сбрасывает кэш публичных текстов; штатный опрос клиента получает новый текст примерно за 30 секунд. Новые сборки мобильных приложений не нужны. Перевод действует и в других местах, где используется то же название через `.tr()`.
