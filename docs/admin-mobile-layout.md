# Админка на телефоне

Адаптивная версия использует те же разделы и действия, что и компьютерная. Откройте меню слева сверху и выберите раздел. Минимальная ширина страницы больше не ограничена 980 пикселями: карточки занимают ширину телефона, широкие группы данных перестраиваются в колонку, панели кнопок переносятся.

Поиск находится под заголовком; кнопка рядом сохраняет текущий вид. Фильтры по умолчанию свёрнуты. Раскрытые фильтры прокручиваются в своей области и не вытесняют список записей. В разделе «Пользователи» отдельно прокручиваются подробные CRM-фильтры. Выбранные значения сохраняются при сворачивании.

Формы редактирования прокручиваются при открытой клавиатуре. Кнопки сохранения доступны внизу окна. Детали записей, документы и верификация адаптированы к узкому экрану. Команды, статусы и правила обработки данных не менялись.

Веб-админка получает изменения после обновления страницы. Для установленного APK админки нужен новый APK; приложения заказчика и уборщицы это изменение не затрагивает.
