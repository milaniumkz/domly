# DOMLY Admin Web: четкая инструкция по админке

Документ для администратора, менеджера или нового сотрудника, которому нужно быстро понять, как пользоваться админ-панелью DOMLY.

Ссылка на админку:

- [https://domly-admin-web.web.app](https://domly-admin-web.web.app)

## 1. Для чего нужна админка

Через админку управляют:

- заказами
- уборщицами
- жалобами
- выплатами
- отзывами
- верификацией
- домами и зонами
- рефералами
- проверкой площади
- видео
- инфо-контентом
- пакетами
- политиками системы

## 2. Кто может войти

В админку входят только сотрудники с доступом по email и паролю.

Роли:

- `Суперадмин`
- `Администратор`
- `Менеджер`

Ограничения:

- `Менеджер` не должен редактировать политики
- `Менеджер` не должен запускать выплаты

## 3. Как войти

1. Открыть [https://domly-admin-web.web.app](https://domly-admin-web.web.app)
2. Ввести рабочий email
3. Ввести пароль
4. Нажать `Войти`

Если вход не проходит:

- проверить логин и пароль
- проверить, выдан ли аккаунту доступ
- если система пишет, что прав нет, нужен аккаунт с admin/manager/superAdmin claims

## 4. Как устроена админка

### Верхняя часть

Сверху есть:

- название панели
- роль текущего пользователя
- строка поиска по текущему разделу
- кнопка `Сохранить вид`
- кнопка `Выйти`

### Левая колонка

Слева находятся все разделы админки.

## 5. Все разделы админки

### 5.1 Дашборд

Нужен для общего контроля.

Что делать здесь:

- смотреть общую ситуацию по системе
- быстро переходить в проблемные разделы
- отслеживать узкие места

Когда открывать:

- в начале дня
- после крупных сбоев
- при росте жалоб

### 5.2 Заказы

Главный рабочий раздел.

Здесь можно:

- смотреть все заказы
- проверять статус
- вручную управлять заказом
- контролировать назначение уборщицы

Что проверять по каждому спорному заказу:

1. оплачен ли заказ
2. назначена ли уборщица
3. верный ли статус
4. не отменен ли заказ
5. нет ли жалобы или спора

Основные статусы заказа:

- `pending_payment`
- `pending_assignment`
- `assigned`
- `in_progress`
- `completed`
- `disputed`
- `canceled`

### 5.3 Жалобы

Здесь работают с проблемными заказами.

Использовать для:

- рассмотрения претензий клиента
- принятия решения по компенсации
- эскалации спорных кейсов

Порядок работы:

1. открыть жалобу
2. посмотреть связанный заказ
3. проверить историю и статус
4. принять решение
5. зафиксировать результат

### 5.4 Платежи

Здесь проверяют оплату заказов.

Использовать для:

- проверки оплаты
- поиска неоплаченных заказов
- разбора проблемных платежей

### 5.5 Выплаты

Здесь контролируют деньги, которые идут уборщицам.

Использовать для:

- проверки начислений
- запуска weekly payout
- сверки сумм

Важно:

- менеджер не должен запускать выплаты
- перед запуском нужно убедиться, что начисления корректны

### 5.6 Отзывы

Здесь видны:

- оценки
- тексты отзывов
- фото, если они приложены

Использовать для:

- контроля качества сервиса
- поиска проблемных исполнителей
- анализа клиентской обратной связи

### 5.7 Чек-листы

Здесь проверяют, что реально было сделано по заказу.

Использовать для:

- контроля работы уборщицы
- проверки выполненных доп. услуг
- разбора споров по выполнению

### 5.8 Уборщицы

Справочник всех исполнителей.

Здесь можно:

- открыть профиль уборщицы
- проверить кластер
- проверить статус верификации
- оценить активность и состояние профиля

### 5.9 Кластеры

Раздел для географии и распределения уборщиц.

Использовать для:

- контроля закрепления по кластерам
- проверки перегрузки зон
- понимания, кто где работает

### 5.10 Расписание

Раздел календаря и слотов.

Использовать для:

- просмотра загрузки
- поиска пересечений
- контроля назначений по дням

### 5.11 Верификация

Один из самых важных разделов.

Здесь проверяются документы уборщиц.

Что должен сделать администратор:

1. открыть заявку уборщицы
2. проверить все документы
3. убедиться, что документы читаемы
4. при необходимости посмотреть срок действия
5. выбрать:
   - одобрить
   - отклонить
6. если отклоняете, указать понятную причину

Какие документы должны быть:

1. селфи
2. фото с удостоверением
3. удостоверение / ID
4. справка о несудимости
5. справка с психдиспансера
6. справка фтизиатрии
7. прописка с eGov

### 5.12 Дома

Раздел домов и жилых комплексов.

Использовать для:

- проверки статуса дома
- контроля подключения
- понимания, активен ли дом

Статусы дома:

- `INACTIVE`
- `IN_PROGRESS`
- `ACTIVE`

### 5.13 Лист ожидания

Раздел домов, которые еще не активированы.

Использовать для:

- просмотра спроса
- анализа домов, где жильцы уже ждут запуск

### 5.14 Зоны покрытия

Раздел по географии сервиса.

Использовать для:

- контроля, где работает сервис
- проверки зон покрытия
- оценки расширения

### 5.15 Рефералы

Раздел реферальной программы.

Использовать для:

- просмотра приглашений
- контроля оплаченных рефералов
- оценки эффективности программы

### 5.16 Проверка площади

Раздел для кейсов расхождения площади квартиры.

Использовать для:

- просмотра спорных заявок
- ручного закрытия кейсов

Что делать:

1. открыть кейс
2. сравнить заявленную и фактическую площадь
3. принять решение
4. закрыть кейс

### 5.17 Видео и обучение

Раздел для управления видео.

Здесь можно:

- добавить видео
- изменить видео
- включить или скрыть видео
- выбрать аудиторию
- отметить видео как обязательное

Поля видео:

- `Заголовок`
- `Описание`
- `Категория`
- `Ссылка на превью`
- `Ссылка на видео`
- `Аудитория`
- `Активно`
- `Обязательное`
- `Новое`

Аудитории:

- `Клиенты`
- `Уборщицы`
- `Обе роли`

Правило:

- если видео должно быть видно всем, выбирать `Обе роли`
- если видео только для уборщиц, выбирать `Уборщицы`

### 5.18 Инфо-контент

Раздел текстов и карточек информации.

Здесь можно менять:

- тексты для пакетов
- тексты для доп. услуг
- тексты для экранов с кнопкой `i`

Поля:

- `Ключ`
- `Заголовок`
- `Короткая информация`
- `Полная информация`
- `Цена`
- `Порядок`
- `Тип`
- `Активно`

### 5.19 Пакеты

Раздел управления пакетами.

Здесь можно:

- добавить пакет
- изменить пакет
- скрыть пакет
- удалить пакет

Какие поля есть у пакета:

- `ID пакета`
- `Название пакета`
- `Частота / подпись`
- `Цена`
- `Порядок`
- `Уборок в месяц`
- `Период выставления, мес.`
- `Скидка, %`
- `Что входит`
- `Активно`
- `Популярный`
- `Квартальный пакет`

Важно:

- пакет в админке и у клиента должен совпадать 1 в 1
- если пакет удален в админке, он не должен оставаться у клиента

### 5.20 Политики

Раздел общих настроек системы.

Здесь можно менять:

- сумму реферального бонуса
- порог активации дома
- допуск проверки площади
- бонусы уборщиц
- пороги статусов уборщиц
- правила вывода денег

Менять этот раздел должен только сотрудник, который понимает последствия.

## 6. Как работать в админке каждый день

### Утром

1. Открыть `Дашборд`
2. Проверить `Заказы`
3. Проверить `Верификация`
4. Проверить `Проверка площади`
5. Проверить `Жалобы`

### В течение дня

1. Следить за оплатами
2. Следить за назначением уборщиц
3. Разбирать спорные кейсы
4. Проверять, нет ли зависших заказов

### Раз в неделю

1. Проверять `Выплаты`
2. Обновлять `Видео и обучение`, если нужно
3. Проверять `Пакеты`
4. Проверять `Политики`
5. Смотреть `Отзывы`

## 7. Частые задачи и что делать

### Если клиент жалуется, что не может заказать уборку

Проверить:

1. заполнен ли профиль
2. указана ли площадь
3. подтверждена ли площадь, если это нужно
4. есть ли активный пакет
5. остались ли уборки
6. есть ли доступные даты

### Если уборщица не может работать

Проверить:

1. заполнен ли профиль
2. прошла ли верификация
3. есть ли назначение в кластер
4. нет ли блокировки по документам

### Если видео не видно

Проверить:

1. активно ли видео
2. правильная ли аудитория
3. заполнена ли ссылка на видео

### Если пакет отображается неправильно

Проверить:

1. правильное ли название
2. правильная ли частота
3. правильная ли цена
4. не скрыт ли пакет
5. нет ли дублирующего пакета

## 8. Что нельзя делать

- не менять вручную спорные бизнес-значения без понимания последствий
- не публиковать видео не той аудитории
- не удалять пакеты без проверки, где они используются
- не запускать выплаты без сверки
- не одобрять верификацию без документов
- не закрывать кейсы площади без проверки

## 9. Минимальный порядок обучения нового администратора

1. Показать вход в админку
2. Объяснить разделы
3. Научить работать с заказами
4. Научить работать с верификацией
5. Показать, как редактировать пакеты
6. Показать, как публиковать видео
7. Показать, где политики и почему их трогать осторожно

## 10. Коротко: что самое важное

Если человек должен быстро понять админку, он должен запомнить:

1. `Заказы` — главный раздел
2. `Верификация` — обязательна для допуска уборщиц
3. `Пакеты` и `Видео` меняют то, что видит клиент
4. `Политики` влияют на всю систему
5. Любое спорное действие сначала проверяется через связанный заказ, клиента или уборщицу
